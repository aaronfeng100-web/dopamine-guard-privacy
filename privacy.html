⚡ 無障礙服務顯著揭露（Prominent Disclosure） ⚡ Prominent Disclosure: Accessibility Service

Astrecho 星迴 依賴 Android AccessibilityService API 來提供核心數位防衛與應用程式攔截功能。請於啟用前詳閱下列聲明：

  • 使用目的：無障礙服務僅用於即時辨識當前正在運行的前景應用程式套件名稱（Package Name）。當您使用的 App 屬於您設定的「受保護/封鎖清單」且使用時間超過每日上限時，App 會即時呈現防衛疊加畫面與覺醒提醒。
  • 絕不收集個人內容：我們絕對不會讀取、記錄或攔截您在螢幕上輸入的任何文字、密碼、聊天訊息、個人對話、金融資料或螢幕顯示內容。
  • 絕不操控裝置：無障礙服務絕不用於自動點擊、手勢模擬、修改系統偏好設定或規避系統安全機制。
  • 完全本機處理：無障礙服務所偵測到的前景套件名稱僅在裝置本機端記憶體即時比對，絕不會外傳至任何遠端伺服器或第三方。

Astrecho utilizes the Android AccessibilityService API to deliver its core digital defense and app intervention features. Please review the following declaration:

  • Purpose of Use: The AccessibilityService is used solely to identify the package name of the currently active foreground application in real time. When a designated restricted app exceeds your daily limit, Astrecho triggers an intervention overlay and mindfulness reminder.
  • No Content Inspection: We never inspect, read, log, or collect your keystrokes, passwords, typed text, chat messages, financial data, or on-screen content.
  • No Device Manipulation: The AccessibilityService is never used for automated clicks, simulated gestures, changing system settings, or bypassing system security.
  • Local-Only Processing: Foreground package detection is executed entirely in-memory on your device and is never transmitted to any remote servers or third parties.

🗑️ 如何刪除您的資料（Data Deletion Policy） 🗑️ How to Delete Your Data

我們尊重並保障您的資料自主權。Astrecho 星迴 採用匿名帳號機制（無需註冊密碼），您可以隨時透過以下方式刪除所有本機與雲端資料：

  1. 刪除裝置本機資料： 於 Android「設定」>「應用程式」>「Astrecho 星迴」選擇「清除儲存空間與快取」，或直接解除安裝應用程式。所有本機設定、快取語句、用量日誌及本機相片將全數被系統清除。
  2. 申請刪除雲端所有關聯資料： 請寄送電子郵件至 dopamineguard.dev@gmail.com，信件主旨註明：Data Deletion Request / 資料刪除申請。 信件內文請附上您在 App 內設定的暱稱或大約使用時間（若無亦可直接提出），我們將於 7 個工作日內徹底刪除。

雲端刪除範圍包括：

  • Cloud Firestore 個人檔案：儲存於 user_profiles 與 users 中的個人設定、時薪估值、目標契約、封鎖名單及社交好友關聯。
  • 好友碼關聯：儲存於 friend_codes 中由系統為您產生的匿名邀請代碼。
  • Firebase Storage 成就照片：若您曾在成長樹中啟用「分享證明照片」，已上傳至 users/{uid}/proofs/ 的證明相片將全數永久清除。

We respect your right to control your personal data. Astrecho uses an anonymous authentication model without requiring email/password accounts. You can delete your local and cloud data at any time:

  1. Delete Local Data: Go to Android Settings > Apps > Astrecho and tap "Clear Data / Storage", or simply uninstall the application. All local preferences, cached quotes, usage logs, and local photos will be wiped immediately by the OS.
  2. Request Deletion of Cloud Data: Send an email to dopamineguard.dev@gmail.com with the subject: Data Deletion Request - Astrecho. We will verify and permanently delete all your cloud-stored data within 7 business days.

What Will Be Permanently Deleted:

  • Cloud Firestore Profiles: All documents in user_profiles and users (nickname, goals, defense contract, blocked app list, friend connections, RPG summary).
  • Friend Codes: The anonymous pairing code generated under friend_codes.
  • Firebase Storage Proof Photos: Any milestone completion photos uploaded to users/{uid}/proofs/ if you opted into proof photo sharing.

1. 我們收集與處理的資料 1. Data We Access and Collect

1.1 您自行填寫的個人檔案與防衛設定 1.1 Profile and Defense Parameters You Provide

在設定個人檔案與防衛契約時，您可自由選擇填寫以下資訊（未填寫項目絕不強制收集）：

  • 暱稱、年齡區間、性別、職業、所在城市/地區（自願文字填寫，無 GPS 定位）
  • 時薪估值、個人里程碑目標、榜樣、家庭與生活連結描述
  • 每日用量上限、自訂封鎖應用程式、模擬防衛契約金與承諾設定
  • 匿名好友代碼（Friend Code）與互相致敬（Respects）紀錄

上述資訊儲存於裝置本機，並透過加密通道同步至 Google Cloud Firestore，用於個人化語句生成與跨裝置設定保存。

When configuring your profile and defense contract, you may voluntarily provide:

  • Nickname, age range, gender, occupation, location description (text-only, NO GPS)
  • Hourly wage estimate, life goals, role models, core motivations
  • Daily app limits, target restricted apps, simulated commitment pledge tokens
  • Anonymous Friend Code and mutual respect interactions

This data is stored locally and synchronized to Google Cloud Firestore via encrypted HTTPS for personalized prompt generation and state persistence.

1.2 相片與媒體檔案（Photos and Media） 1.2 Photos and Media

我們絕不讀取您未選取的相片，亦不存取您的相機硬體：

  • 自訂覺醒背景圖片：當您主動更換語句背景時，僅透過系統標準相片挑選器（Photo Picker）取得您自行勾選的照片，經本機裁切後儲存在裝置內部目錄，絕不上傳雲端。
  • 成長成就證明相片（選用）：在完成成長樹挑戰任務時，您可以主動挑選單張相片作為完成證明儲存於本機。僅當您在設定中主動開啟「分享證明照片」選項時，該相片才會上傳至 Google Firebase Storage（users/{uid}/proofs/）以供社群好友查看。

We never inspect unselected photos and do not access your camera hardware:

  • Custom Quote Backgrounds: When you customize quote backgrounds, we use the standard system Photo Picker to access only the single or batch images you explicitly select. Cropped copies are stored strictly on your local device storage and are never uploaded to the cloud.
  • Growth Milestone Proof Photos (Optional): When completing a habit milestone, you may select an image as proof of completion. Only if you explicitly enable "Share Proof Photos" in settings will that specific photo be uploaded to Google Firebase Storage (users/{uid}/proofs/) for connected friends to view.

1.3 裝置狀態、用量與應用程式清單 1.3 Device Status, Usage, and App List

  • 用量統計（PACKAGE_USAGE_STATS）：取得各應用程式的前景累計時間，以計算今日是否超過限制。
  • 前景套件名稱（無障礙服務）：即時辨別當前開啟的應用程式是否在受保護清單中（詳見上方顯著揭露）。
  • 應用程式挑選清單：App 未申請廣泛的 QUERY_ALL_PACKAGES 權限，僅在本機透過標準 Launcher 意圖查詢可啟動的桌面應用供您挑選受保護項目。未勾選之其他 App 資訊絕不上傳或紀錄。
  • 匿名使用者 ID（Firebase Anonymous Auth）：系統採用 Firebase 匿名身分驗證簽發隨機 UID（格式如 auth_uid 或 device_...），無須輸入 Email 或密碼即可關聯您的雲端檔案。
  • Usage Statistics (PACKAGE_USAGE_STATS): Reads daily foreground usage time of apps to track against your self-imposed limits.
  • Foreground Package Name (Accessibility Service): Identifies whether the active app is on your restricted list (see Prominent Disclosure above).
  • App Selection List: The app does NOT request the high-risk QUERY_ALL_PACKAGES permission. It queries launchable apps locally via Android Launcher Intent so you can pick target apps. Unselected apps are never cataloged or uploaded.
  • Anonymous User ID (Firebase Anonymous Auth): The app uses Firebase Anonymous Authentication to generate a unique random UID without requiring email or password credentials.
